# 估值分析(相对估值 + 阶段特征 + 预期差)

## R — 原文 (Reading)

> "行业相对估值=行业市盈率÷全部A股市盈率。当上述公式得出的比值大于1时，说明行业与整个大盘相比，估值更高。"
>
> — 肖璟，《如何快速了解一个行业》第6章 第3节

## I — 方法论骨架 (Interpretation)

判断一个行业估值贵不贵,最大的噪音是宏观(央行放水会让所有行业都"贵")。作者的办法是**相对估值**:行业市盈率 ÷ 全 A 股市盈率。这是一个会随大盘自动调整的标尺,能把货币宽松等宏观因素隔离掉,露出行业自身生命周期阶段的估值特征。

**估值由两个对象决定**:投资者(需求方:能力=钱多不多受货币政策影响、意愿=风险偏好)和资产(供给方:赔率=规模性/盈利性、概率=可行性/防守性)。赔率概率与基本面四维度一一对应,且高赔率高概率一般难兼得。

**各生命周期的估值特征截然不同**:导入期围绕"梦想"和"故事"展开(市梦率,上得快下得也快);成长前期业绩超预期、估值冲高(但要警惕交易拥挤);成长后期增速放缓、高估值难以为继;成熟期估值收缩(但龙头进阶可提升);衰退期三种走向(第二曲线/稳定周期化/被替代)各有不同估值逻辑。**市场围绕预期差交易**——股票不会等经济真变差才跌,投资研究的目标是发现预期差。

**宏观传导用货币三价格拆**:货币购买力(通胀,影响市场规模与成本)、利率(未来货币衡量现在货币,影响估值与商业模式)、汇率(影响进出口与国际定价商品)。三者变化对行业影响各异。

## A1 — 书中的应用 (Past Application)

### 案例 1:空调行业完整估值史(1994-2018)
- **问题**: 一个行业从导入到成熟,估值怎么演变?
- **方法论的使用**: 导入期(渗透率<5%)相对估值从 0.8 倍回落到 0.4 倍;成长期(渗透率 16→81 台/百户)相对估值从 0.4 倍翻番到 0.8 倍,但 2000 年前后价格战+库存危机致回落;成熟期格力美的靠渠道下沉+出海第二曲线使估值回到 0.8 倍并稳定。
- **结论**: 各阶段估值特征完整验证:导入期看梦想、成长期看业绩、成熟期看龙头进阶。
- **结果**: 相对估值从 0.4→0.8→0.8,完整走完生命周期。

### 案例 2:歌尔股份戴维斯双击——智能手机渗透率估值史
- **问题**: 智能手机产业链在渗透率提升期的估值如何变化?
- **方法论的使用**: 导入期(2007-2010 渗透率到 22%)相对估值快速提升,2010 年底歌尔市盈率约 90 倍;成长期(22%→50%)业绩持续超预期但增速放缓,估值回落;成熟期渗透率增速放缓,估值中枢降至 20-40 倍。
- **结论**: 歌尔 2009-2010 股价翻 6 倍,估值贡献 2.4 倍(典型戴维斯双击);成长后期增速放缓高估值难以为继。
- **结果**: 估值中枢从 80-120 倍降至 20-40 倍。

### 案例 3:茅台概率支撑高估值
- **问题**: 2019-2023 年茅台增速只有 10% 出头,为什么还能拿 30-40 倍市盈率?
- **方法论的使用**: 用"概率"解释——茅台无与伦比的品牌力和定价权、稳定可靠的业绩表现(高防守性+高盈利性)支撑高概率,即使赔率不高也能维持高估值。
- **结论**: 概率高可对冲赔率低,两者权衡决定估值。
- **结果**: 茅台长期维持 30-40 倍市盈率,验证概率对估值的支撑。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想知道"这个行业现在贵不贵、能不能进"时。
2. 判断某行业估值高企是"泡沫"还是"合理",该用什么尺子量时。
3. 分析宏观(降息/加息/汇率变动)对某行业估值的影响时。
4. 判断成长期行业的交易拥挤度风险(要不要警惕回调)时。

### 语言信号 (用户的话里出现这些就应激活)

- "这个行业估值贵不贵?" / "为什么它估值这么高/低?"
- "该用什么估值方法?" / "市盈率合理吗?"
- "相对估值 / 估值中枢 / 泡沫 / 交易拥挤 / 预期差"
- "is this sector overvalued?" / "valuation" / "PE ratio" / "expensive or cheap"

### 与相邻 skill 的区分

- 与 `competitive-landscape` 的区别: 格局决定盈利性(基本面),估值是给盈利定价——格局分析在前,估值在后。
- 与 `industry-lifecycle-staging` 的区别: 生命周期判定行业所处阶段,本 skill 把阶段映射到对应的估值特征与估值方法。
- 与 `prosperity-indicator-system` 的区别: 景气度验证"业绩是否兑现"(基本面验证),估值是"预期与价格"——景气度高可放宽估值要求(成长期),两者互补。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先判定阶段,选对估值尺子**
   - 确认行业所处生命周期阶段(渗透率)。
   - 对应估值风格:导入期→VC/梦想逻辑(看潜在空间与团队);成长期→成长股逻辑(看增速);成熟期周期化→周期股逻辑;衰退期→三种走向各自定价。
   - 判停条件: 若行业仍处导入期且商业模式未验证,估值意义有限——先过 `business-model-feasibility`,估值交给未来。
   - 完成标准: 明确"什么阶段 + 用什么估值风格"。

2. **算相对估值,隔离宏观噪音**
   - 行业市盈率 ÷ 全 A 股市盈率,得到相对估值比值(>1 高于大盘,<1 低于大盘)。
   - 检查宏观背景(货币政策、利率、汇率)对绝对估值的扭曲程度。
   - 对照该阶段的估值特征(导入期高波动、成长前期冲高、成熟期收缩等)判断当前相对估值是否合理。
   - 完成标准: 相对估值数值 + 与历史/阶段特征的对照结论。

3. **综合概率赔率 + 交易拥挤度 + 预期差,输出判断**
   - 拆估值影响要素:赔率(规模性/盈利性)、概率(可行性/防守性),判断当前定价反映的是哪个。
   - 若处成长/主题热门期,用交易拥挤度(成交额占比、换手率、融资情绪)评估筹码风险。
   - 追问预期差:市场已经 price in 了什么?还有哪些边际变化没被定价?
   - 完成标准: 输出"贵/合理/便宜 + 依据(相对估值+阶段特征+拥挤度+预期差)"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单家公司估值(DCF/分部)——那是公司分析,本 skill 是行业中观。
- 短期交易择时——估值是中长期结构判断。
- 非投资目的(求职/创业/学术)分析时——估值与景气度是投资专用环节,其他场景应弱化(ce48)。

### 作者在书中警告的失败模式

- **交易拥挤过高**(ce17):2021 年末新能源板块,基本面没问题但成交额占比/换手率历史高位,微小利空就引发深度回调——估值再合理也要看筹码结构。
- **导入期市梦率泡沫**(ce39):Gartner 曲线期望膨胀期,产业化没落地估值先上天,元宇宙/区块链/早期 AI 都经历过泡沫破裂。
- **预期差失效**:市场已充分定价的信息不产生超额收益,追已经明牌的高增长反而接盘。
- **赔率概率不可兼得**(p26):业绩年均增速 30%+ 的公司可遇不可求,两全很难。

### 作者的盲点 / 时代局限

- **市场相对有效假设**(阶段 0 批判):"市场围绕预期差交易"假设定价相对有效,但 A 股散户占比高、行为偏差大,解释力打折。
- **A 股语境**(ce49):相对估值以全 A 为分母,迁移到美股需换成相应基准;政策面对估值影响权重高。
- **数据时效**(ce50):书中各阶段估值倍数案例截至 2023-2024。

### 容易混淆的邻近方法论

- 与"竞争格局分析"混淆:格局(盈利性)是估值(赔率概率)的基本面输入,不是同一层。
- 与"景气度"混淆:估值是"预期与价格",景气度是"业绩验证"——景气度高可放宽估值要求(成长期),但拥挤度高不可放宽。
