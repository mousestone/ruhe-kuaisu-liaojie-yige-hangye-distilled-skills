# 产能周期判断(四阶段 + 顶底信号)

## R — 原文 (Reading)

> "产能周期包括'供不应求–产能激增–产能出清–格局改善'4个阶段……当外来者跑进来扩产能的时候，行业通常离波峰（高位）不远了；而当龙头主动减产能的时候，行业已处于相对底部。"
>
> — 肖璟，《如何快速了解一个行业》第5章 第1节

## I — 方法论骨架 (Interpretation)

周期行业的命运由供需错配的循环主导,共四阶段:供不应求(产能利用率高、价格好)→产能激增(外来者涌入,供大于求,价格跌)→产能出清(弱者淘汰)→格局改善(供给收缩,利润恢复)。循环的根源是企业家的**预期差**——高估自己能吃下的份额,反应速度滞后于市场。

**识别所处阶段的定性信号**——产能扩张分三阶段:龙头被动扩(只添设备应付当前需求)→龙头主动扩(看好前景大规模扩张)→外来者无序扩(门外汉盲目涌入,最危险)。**外来者涌入扩产能时行业离顶部不远;龙头主动减产时行业已接近底部。**

**定量信号**:资本性支出÷折旧摊销之比,跌破 1.5 甚至 1 提示"供给相对收缩、格局有望改善"的底部;库存历史高位=供过于求危险信号,历史低位=供不应求或磨底。

**辅助信号**:卖方分析师底部不推荐、顶部跳空上调评级;行业内玩家退出(底部三信号之一:龙头减产+玩家退出+卖方不推荐)。

**两个例外要警惕**:龙头逆势扩张(有政府/银行/资本市场输血)和龙头主动打价格战(为清场)会打破常规信号。

## A1 — 书中的应用 (Past Application)

### 案例 1:小明面馆——四阶段思想实验
- **问题**: 用一个完整故事演示产能周期的全部阶段。
- **方法论的使用**: 阶段 1 供不应求(燃气灶不停、厨师抱怨);阶段 2 产能激增(小A/小B/小C 跟风开面馆,小C 一口气开 50 家,价格从 150 元降到 75 元);阶段 3 产能出清(小C 关门大吉,小明关效益差的店);阶段 4 格局改善(供给收缩,生意回暖)。
- **结论**: 完整呈现四阶段+三阶段扩张(龙头被动-主动-外来者无序)。
- **结果**: 思想实验演示方法论,小C 出清后小明生意回暖。

### 案例 2:共享单车——企业家预期差导致过度投放
- **问题**: 共享单车为什么集体崩盘?
- **方法论的使用**: 所有参与者大量投资,产能过剩、单车过度投放,同时上游通胀(单车造价、运输人力成本上涨)。
- **结论**: 企业家高估自己能吃下的份额,造成供需缺口。
- **结果**: 行业产能过剩、大量企业倒闭,验证预期差风险。

### 案例 3:空调 2000 年前后价格战
- **问题**: 空调行业库存危机如何形成、如何出清?
- **方法论的使用**: 2001-2002 年库存超 600 万台形成严重积压(被动补库存);龙头主动打价格战清场,2001-2004 年内销均价从 2835 元降至 1600 元。
- **结论**: 价格战+产能出清后格局改善,集中度提升。
- **结果**: CR3 从 37.37% 升至 54.66%,三足鼎立格局形成。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 判断一个周期行业(煤炭/钢铁/猪/光伏/半导体/航运)是不是见底了、该不该进场时。
2. 判断产能过剩到什么阶段、要不要规避时。
3. 看到"某行业疯狂扩产/疯狂建厂"的新闻,想判断是不是顶部信号时。
4. 分析成熟期"稳定周期化"行业的布局时机时。

### 语言信号 (用户的话里出现这些就应激活)

- "XX 行业到底了没有?" / "该不该抄底?" / "见底了吗?"
- "产能过剩" / "产能出清" / "都在扩产" / "库存高企"
- "周期股 / 周期底部 / 景气反转"
- "is this cycle bottoming?" / "capacity cycle" / "destocking" / "supply glut"

### 与相邻 skill 的区分

- 与 `competitive-landscape` 的区别: 产能周期是解释横向集中度变化的机制,竞争格局更全面(含纵向);本 skill 更聚焦"顶部/底部识别"这个择时任务。
- 与 `prosperity-indicator-system` 的区别: 景气度是日常高频跟踪(月/周/日),产能周期是中期供需结构(季度/年级)——时间尺度不同,产能周期判断可以指导景气度指标的构建。
- 与 `industry-lifecycle-staging` 的区别: 生命周期是几十年的阶段(渗透率),产能周期是几年一轮的供需波动——只有成熟期"稳定周期化"的行业才适用产能周期。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认适用性:该行业是否已进入"稳定周期化"的成熟期**
   - 判断渗透率是否见顶、行业是否由供需波动主导(而非渗透率驱动的成长)。
   - 若仍是成长驱动,产能周期不适用,回到 `industry-lifecycle-staging`。
   - 完成标准: 一句"适用/不适用 + 理由"。

2. **用定性+定量信号定位当前阶段**
   - 定性: 谁在扩产(龙头被动/龙头主动/外来者无序)?谁在减产?有没有玩家退出?
   - 定量: 资本性支出÷折旧摊销是否跌破 1.5/1?库存处于历史高位还是低位?
   - 辅助: 卖方分析师的推荐态度(底部不推荐、顶部跳空上调)。
   - 判停条件: 若发现龙头逆势扩张(有非经营现金流输血)或龙头主动打价格战,标注"常规信号可能失效",改用供需平衡表+基本面数据验证。
   - 完成标准: 定位到四阶段之一(供不应求/产能激增/产能出清/格局改善)+ 支持信号清单。

3. **输出阶段判断与行动含义**
   - 产能激增+外来者涌入 → 顶部风险高,谨慎追高。
   - 龙头减产+玩家退出+卖方不推荐+资本开支比<1.5 → 底部区域,关注布局。
   - 完成标准: 输出"当前阶段 + 顶/底倾向 + 关键监测变量"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 渗透率仍在快速提升的成长期行业——那由成长逻辑主导,不是供需周期主导。
- 单只个股的技术面择时——本 skill 是行业供需结构分析。

### 作者在书中警告的失败模式

- **龙头逆势扩张**(ce15):龙头凭银行授信/政府融资/定增在下行期逆势扩产能,打破"产能周期=集体预期"规律,底部信号失效。
- **龙头主动打价格战**(ce15 / c39):特斯拉 2022 年、空调 2000 年,主动压价清场不是正常供需信号。
- **衰退期特殊情形**(ce16):煤炭供给收缩快于需求下降、价格反而上涨——需比较收缩速度,不能机械套"衰退=没机会"。

### 作者的盲点 / 时代局限

- **数据时效**(ce50):书中具体数值(资本开支比阈值 1.5 等)是经验值,不同行业差异大。
- **政策干预**:中国供给侧改革/限产政策会人为改写供需曲线,框架对政策主导行业的适配需补足(ce49)。

### 容易混淆的邻近方法论

- 与"库存周期"(基钦周期)混淆:库存周期是产能周期的同步/滞后表现之一(书中单列四阶段),判断顶底时要两者结合。
- 与"生命周期阶段"混淆:产能周期是成熟期内的短周期波动,不是生命周期本身。
