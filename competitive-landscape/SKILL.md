# 竞争格局分析(横向 + 纵向)

## R — 原文 (Reading)

> "整个行业的竞争格局可以从横向和纵向分开看。横向格局研究的是，同行间是怎么分蛋糕的；纵向格局研究的是，上下游是怎么分蛋糕的。"
>
> — 肖璟，《如何快速了解一个行业》第5章

## I — 方法论骨架 (Interpretation)

看一个行业的竞争格局,拆成两刀:一刀横着切(同行之间),一刀竖着切(上下游之间)。两刀都理想,行业里的企业才好赚钱。

**横向格局——同行分蛋糕**。关键指标是行业集中度(CRn)。两条规律要记住:集中度随产业生命周期**先降后升**(导入期少数厂商先行→成长期大量涌入摊薄→成熟期弱者淘汰回升);集中度与宏观经济**反向变动**(经济下行,龙头抗风险,中小企业被淘汰,集中度提升)。注意两个坑:数据终端算的 CRn 只统计上市公司,对大行业小公司的行业(餐饮)会虚高到 90%+(失真);集中度天花板因行业属性而异(空调 CR3 70% 但白酒 CR3 只有 10%-20%),不能用一个行业的天花板外推另一个。

**纵向格局——上下游分蛋糕**。产业链利润分配取决于各环节的**议价意愿**(取决于商品在下游的价值占比+行业所处阶段:成长期大家都有肉吃、议价意愿弱;成熟期开始互相博弈)和**议价能力**(取决于行业集中度+供需情况:最供不应求、技术含量最高的环节拿走利润大头)。用毛利率 + 占用上下游资金的能力判断地位。

**成熟期的一条投资纪律**:行业进入成熟期后不要押注整个赛道,而要精选产业链中最赚钱的环节——那个环节赚的钱可能是从上下游"抢"来的,增速远高于产业链整体。

## A1 — 书中的应用 (Past Application)

### 案例 1:光伏产业链利润分配——供需紧平衡下的议价能力
- **问题**: 光伏产业链很长,钱到底被哪个环节赚走了?
- **方法论的使用**: 用各环节毛利率判断纵向地位。2019 年硅料/硅片毛利率 20%+、电池片 5.7%;2021 年硅料因供不应求毛利率飙至近 80%,电池片接近 0%。
- **结论**: 最供不应求、技术含量最高、无法绕开的环节拿走利润大头。
- **结果**: 2021 年硅料环节拿走光伏产业链绝大部分利润。

### 案例 2:新能源车——横向 CR4 高但成长期不必过度关注
- **问题**: 判断新能源车行业竞争格局。
- **方法论的使用**: 横向:比亚迪独领风骚,CR4>50%,但成长期不必过度关注横向格局;纵向:用各环节毛利率判断——采矿及回收(31.83%)、隔膜电解液(27.59%)最赚钱,整车制造毛利率平平。
- **结论**: 成长期厂商忙于抢市场、议价意愿弱,整车环节不赚钱;最赚钱的是产业链瓶颈环节。
- **结果**: 验证"成长期押注最赚钱环节"的判断。

### 案例 3:空调价格战——集中度提升机制
- **问题**: 2000 年前后空调行业为什么卷到极致?集中度如何变化?
- **方法论的使用**: 低门槛高盈利吸引大量厂商涌入,2001-2002 年形成严重库存危机(库存超 600 万台);龙头主动打价格战(奥克斯发布《空调制造成本白皮书》公开成本)清场。
- **结论**: 价格战淘汰中小玩家,集中度提升。
- **结果**: CR3 从 2003 年 37.37% 升至 2006 年 54.66%,形成格力/美的/海尔三足鼎立。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 分析一个行业"为什么这么卷/这么赚钱"、格局好不好时。
2. 想知道产业链上哪个环节最值得做/最赚钱时。
3. 判断某行业竞争是否会加剧、龙头能否守住份额时。
4. 评估一家公司在产业链中的议价地位时。

### 语言信号 (用户的话里出现这些就应激活)

- "这个行业格局怎么样?" / "为什么这么卷?"
- "产业链哪个环节最赚钱?" / "谁有议价权?"
- "集中度 / CR3 / CR5 / 市占率" / "内卷 / 价格战"
- "competitive landscape" / "market concentration" / "who captures the profit"

### 与相邻 skill 的区分

- 与 `moat-analysis` 的区别: 护城河是"单个玩家凭什么强",竞争格局是"整个行业蛋糕怎么分"——一个微观一个中观,护城河分析可作为竞争格局的输入。
- 与 `capacity-cycle-timing` 的区别: 产能周期是解释横向格局集中度变化的核心机制,但竞争格局还含纵向维度与集中度规律;产能周期更聚焦"顶部/底部信号"。
- 与 `industry-valuation` 的区别: 竞争格局决定盈利性(基本面),估值是给盈利定价——格局分析在前,估值在后。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先横向:算集中度,看阶段与宏观背景**
   - 查 CRn 数据并核实分子分母口径——若行业上市公司少(大行业小公司),数据终端 CRn 会虚高,需改用"上市公司营收加总÷全行业测算规模"。
   - 结合生命周期阶段(先降后升)与宏观周期(反向变动)解释当前集中度水平与趋势。
   - 判停条件: 若行业处于导入/成长早期,横向格局不重要(厂商忙于抢市场),直接转到纵向分析。
   - 完成标准: 写出当前集中度水平 + 趋势 + 与生命周期/宏观的对位判断。

2. **再纵向:用毛利率和议价结构判断利润归属**
   - 画出产业链上中下游,标注各环节毛利率。
   - 对每个环节评估议价意愿(价值占比+阶段)与议价能力(集中度+供需+技术含量)。
   - 找出"最供不应求/技术含量最高/无法绕开"的环节——利润大头通常在这里。
   - 完成标准: 标出"利润在产业链的哪个环节、为什么"。

3. **综合判断格局好坏,给出盈利性结论**
   - 横向+纵向两维合成:横向不激烈(或集中度提升中)+ 纵向有议价权的环节 → 盈利好。
   - 若行业已成熟并周期化,给出"优先投资最赚钱环节"的具体指向。
   - 完成标准: 输出"格局判断(好/中/差) + 最赚钱环节 + 一句 So what"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 分析单家公司战略(那是公司层面分析)——本 skill 是行业层面。
- 判断短期股价走势——格局是结构判断,不解释短期波动。

### 作者在书中警告的失败模式

- **上市公司 CRn 虚高**(ce13):餐饮住宿 CR8=90.85% 是失真数据,因为它只统计上市公司、分母本身就小。
- **集中度天花板刻舟求剑**(ce14):用空调/手机 70% 的 CR3 外推白酒(实际 CR3 10%-20%),会得出"白酒还有巨大提升空间"的错误结论。
- **龙头逆势扩张/主动价格战**(ce15):特斯拉 2022 年价格战、2000 年空调价格战打破了"产能周期=企业家集体预期"的规律,顶部/底部信号会失效。
- **衰退期一票否决**(ce16):煤炭供给收缩快于需求下降时价格反而上涨——要比较供给与需求收缩速度,不能只看生命周期标签。

### 作者的盲点 / 时代局限

- **案例行业集中**(ce49):消费品、新能源、白酒、家电为主,对服务业、平台经济、内容产业的迁移需自行补足。
- **政策主导型行业**:中国政策面对格局影响权重高,海外市场需调整。

### 容易混淆的邻近方法论

- 与"护城河分析"混淆:行业格局(分蛋糕) vs 个体壁垒(守蛋糕)。
- 与"市场规模测算"混淆:算盘子大小 vs 算蛋糕怎么分。
