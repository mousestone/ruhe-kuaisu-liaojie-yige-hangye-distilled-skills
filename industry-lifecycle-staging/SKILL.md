# 产业生命周期渗透率判定与阶段研究重点

## R — 原文 (Reading)

> "一旦行业的渗透率达到15%~20%，行业就会进入快速提升的阶段，此时对应的是行业的成长期。但是渗透率提升至35%~40%以后，行业发展的脚步往往就开始放慢了，此时对应的是行业的成熟期。"
>
> — 肖璟，《如何快速了解一个行业》第1章 第2节

## I — 方法论骨架 (Interpretation)

判断一个行业所处阶段,不要看它"发展了几年",也不要用营收增速的斜率——这两者都会把短期的供需波动误当成长期趋势。真正的判据是**渗透率**:已经被多少比例的潜在用户接受了。渗透率 15%~20% 是导入期进入成长期的转折点,35%~40% 是进入成熟期的转折点。

关键在口径:渗透率要算"新增"而非"存量"——汽车要看新车渗透率而不是保有量渗透率,因为替换周期长达十年,存量数据会被历史基数稀释,掩盖当下的需求结构变化。

判定阶段后,研究重点随之改变:**导入期**看商业模式能不能跑通(可行性)、**成长期**看市场天花板有多高(规模性)、**成熟期**看护城河与竞争格局(防守性+盈利性)、**衰退期**把重心转移到替代品上。用同一套模板分析所有行业,每个维度都覆盖到却抓不住关键,等于白做。成熟期行业若出现第二增长曲线,要回到导入期的分析逻辑重新评估。

## A1 — 书中的应用 (Past Application)

### 案例 1:新能源汽车——新车渗透率 vs 存量渗透率的口径选择
- **问题**: 按存量口径,新能源车 2024 年 6 月底只占汽车保有量 7.18%,按此判断会得出"仍处导入期"的错误结论。
- **方法论的使用**: 作者指出汽车替换周期约 10 年,存量渗透率被历史燃油车基数稀释,应改用新车渗透率(2023 年稳定 30% 以上,11 月破 40%),并结合销量同比两位数增速远超 GDP。
- **结论**: 判定新能源车处于"导入期向成长期过渡"。
- **结果**: 2023 年 2 月后新车渗透率稳定 30% 以上、11 月破 40%,销量保持两位数增长,验证成长期判断。

### 案例 2:煤炭——衰退期不等于没机会
- **问题**: 煤炭是高污染能源、迟早被替代,看似"夕阳行业"。
- **方法论的使用**: 按生命周期看它处于衰退期,研究重点应转向替代品;但作者进一步比较供给收缩与需求下降的速度——煤炭企业不扩产、淘汰落后产能,而短期新能源无法完全替代(光伏风电靠天吃饭需火电调峰),经济持续发展对能源需求仍在增加。
- **结论**: 供给收缩快于需求下降,煤炭价格短期上涨,行业估值提升。
- **结果**: 龙头短期利好,证明衰退期行业也有"回光返照"式机会,不能一票否决。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想快速判断一个陌生行业处于什么发展阶段、值不值得深入研究时。
2. 准备研究某行业,但不清楚该把精力花在哪方面(市场规模?护城河?竞争?)时。
3. 在求职面试/创业/投资中,被问"你怎么看 XX 行业"需要先立框架时。
4. 看到某个行业渗透率数据,想判断它是否已进入放量或瓶颈期时。

### 语言信号 (用户的话里出现这些就应激活)

- "这个行业处于什么阶段?" / "XX 行业值不值得研究?"
- "导入期 / 成长期 / 成熟期 / 衰退期" / "渗透率多少了?"
- "该重点看这个行业的哪方面?" / "我应该从哪入手分析?"
- "What stage is this industry in?" / "is this industry still growing?" / "penetration rate"

### 与相邻 skill 的区分

- 与 `business-model-feasibility` 的区别: 本 skill 判定阶段并决定研究权重;只有导入期才需要深挖商业模式可行性,那是下一个 skill 的活。
- 与 `market-sizing` / `moat-analysis` / `competitive-landscape` 的区别: 本 skill 是入口框架,只负责"判定阶段 + 指路",具体维度分析由对应 skill 承接。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **界定行业颗粒度并选定渗透率口径**
   - 明确行业边界(横向细分 vs 纵向产业链,借用申万/GICS 等现成分类统一口径)。
   - 判断该行业产品是"快消/高频"还是"耐用品/长替换周期":后者必须用新增渗透率而非存量渗透率。
   - 完成标准: 写出明确的行业定义 + 采用哪种渗透率口径及理由。

2. **取渗透率数据,对照阈值判定阶段**
   - 查找该行业(及对标成熟市场)的渗透率数据,标注数据截止时间。
   - 对照经验阈值: <15% 导入期;15%~20% 进入成长期;35%~40% 进入成熟期。
   - 交叉验证: 结合销量增速、用户群体结构,避免线性外推把一次性需求扰动当趋势。
   - 判停条件: 若渗透率 >40% 且该行业出现第二增长曲线信号(新技术/新客群),则回到导入期逻辑重新分析;否则继续。
   - 完成标准: 写出阶段判定(导入/成长/成熟/衰退) + 一句支持证据。

3. **按阶段确定研究重点,并指出下一步应调用哪个维度**
   - 导入期 → 商业模式可行性(business-model-feasibility);成长期 → 市场规模(market-sizing);成熟期 → 护城河 + 竞争格局(moat-analysis / competitive-landscape);衰退期 → 替代品分析。
   - 明确"这个阶段最担心/最重要的一件事"是什么,避免模板化平均用力。
   - 完成标准: 输出阶段 → 研究重点 → 建议调用的下游分析,一句话 So what。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 分析对象是单家公司、聚焦财务报表时——那是公司分析,不是行业阶段判定。
- 行业边界模糊、口径未统一时直接套用——两个口径算出的阶段会截然不同(ce09 万亿 vs 千亿之争)。

### 作者在书中警告的失败模式

- **渗透率阈值不是定律**(ce47):15%~20%、35%~40% 是经验值,不同行业(耐用品/快消、toB/toC、政策主导/市场主导)差异很大,需结合其他信号交叉验证,不能机械套用。
- **口径用错**(ce08):对长替换周期产品(汽车)用存量渗透率会误判为导入期;不同时报告存量与新增两个口径会失真。
- **用时间或曲线斜率划分**(ce02):营收增速起伏大,无法区分短期波动与生命周期切换;纯线性外推(ce03)会把疫情/补贴等一次性需求当成趋势。

### 作者的盲点 / 时代局限

- **数据时效**(ce50):书中具体阈值与案例数据截至 2023-2024,新能源车渗透率等快速迭代行业需自行更新。
- **A 股语境**(ce49):政策面权重高是中国语境特征,迁移到美股或纯市场化行业需补足。

### 容易混淆的邻近方法论

- 与"景气度高频跟踪"(prosperity-indicator-system)混淆:本 skill 判定长期阶段,景气度是同一阶段内的短期高频验证,两者时间尺度不同。
