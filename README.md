# 如何快速了解一个行业 Skill

一套可直接使用的 AI skill 工具包——把《如何快速了解一个行业》(肖璟) 中的核心方法论:以**产业生命周期**为核心框架,用渗透率划分行业所处阶段,按阶段确定分析重点(导入期看可行性、成长期看规模性、成熟期看防守性与盈利性),叠加估值、外部因素与景气度跟踪,系统判断一个行业的投资价值——拆成了 12 个可单独触发、也可组合调用的方法论模块。

这不是一本书的摘要页。书是这些 skill 的来源,不是首页主角。

## 这套 skills 能解决什么问题

- 面对一个陌生行业,不知道从哪里入手(用渗透率定阶段是全书入口)
- 投资早期项目,不确定商业模式能不能跑通(销售可行性 + 利润可行性两步)
- 想知道一个行业的天花板有多大,不知道用什么口径估算(TAM/SAM/SOM 三口径)
- 分不清"龙头有护城河"和"龙头有成本优势",误把后者当长期壁垒
- 周期性行业不知道现在该不该进场(产能周期四阶段 + 顶底信号)
- 不同生命周期的行业估值方法不一样,该用什么锚(相对估值 + 阶段估值 + 赔率概率)
- 拿到一堆研报和数据不知道先信哪个(来源筛选纪律 + 假设驱动 + 金字塔提炼 + SCQR 故事线)

## 蒸馏了什么

从《如何快速了解一个行业》中提取了 12 个经过三重验证的 skill,覆盖两个维度:

### 框架篇 — 判断一个行业值不值得研究 (投资/决策视角)

- [`industry-lifecycle-staging`](./industry-lifecycle-staging/SKILL.md) — 用渗透率判定行业处于导入/成长/成熟/衰退哪一阶段,并按阶段确定研究重点。全书入口。
- [`business-model-feasibility`](./business-model-feasibility/SKILL.md) — 两步法评估早期商业模式:销售可行性(时间/空间对标+频次弹性)+ 利润可行性(UE 模型+终局视角)。
- [`market-sizing`](./market-sizing/SKILL.md) — TAM/SAM/SOM 三口径 + 需求/供给/供需匹配三法测算市场规模,把未知量拆成易得已知量。
- [`moat-analysis`](./moat-analysis/SKILL.md) — 护城河只有两种构造(资源垄断+网络效应),成本优势只是结果;用客户决策/购买/使用三环节检查客户关系护城河。
- [`competitive-landscape`](./competitive-landscape/SKILL.md) — 横向(集中度)+纵向(议价)两维分析行业格局,含集中度先降后升、成熟期投最赚钱环节等规律。
- [`capacity-cycle-timing`](./capacity-cycle-timing/SKILL.md) — 产能周期四阶段 + 顶底信号(外来者扩产=顶、龙头减产=底、资本开支比<1.5=底),周期行业择时。
- [`industry-valuation`](./industry-valuation/SKILL.md) — 相对估值(行业 PE ÷ 全 A)隔离宏观噪音 + 生命周期各阶段估值特征 + 赔率概率 + 交易拥挤度 + 预期差。
- [`prosperity-indicator-system`](./prosperity-indicator-system/SKILL.md) — 构建高频景气度指标体系(前瞻+同步两类,纵向产业链+横向类别两条路径),持续验证中长期判断。

### 方法篇 — 怎么研究一个行业 (通用研究能力)

- [`hypothesis-driven-research`](./hypothesis-driven-research/SKILL.md) — 研究底层方法论:假设 → MECE 拆解 → 验证子假设;深度差是持续创造财富的唯一可靠前提。
- [`research-source-filtering`](./research-source-filtering/SKILL.md) — 评估与交叉验证资讯源:研报四思路、报喜不报忧即信号、专家访谈纪律、数据口径与立场检查。
- [`pyramid-insight-extraction`](./pyramid-insight-extraction/SKILL.md) — 金字塔四步从资讯中提炼核心观点,用 So what 追问区分"总结"与"提炼"。
- [`scqr-storyline`](./scqr-storyline/SKILL.md) — SCQR 故事线输出,按四类受众调整顺序(路人 CQSR / 观众 SCQR / 大老板 RSCQ / 直属领导 R)。

提取过程从候选框架、原则、案例、反例和术语中筛选,最终保留 12 个可迁移、可触发、可验证的方法论单元。

## 效果示例

### 示例 1:面对一个陌生行业,怎么入手

**用户问题**

"老板让我研究'低空经济',我对这个领域一无所知,该从哪里开始?"

**skill 如何判断**

- 触发 `industry-lifecycle-staging`——这是全书入口,先用渗透率判断行业阶段(**15%~20% 进入成长期、35%~40% 进入成熟期**),按阶段确定研究重点
- 导入期(< 15%):重点看`business-model-feasibility`(销售+利润可行性)
- 成长期(15%-35%):重点看`market-sizing` + `moat-analysis`(规模+护城河)
- 成熟期(> 35%):重点看`competitive-landscape` + `industry-valuation`(格局+估值)

**最终回答示例**

> 不要直接找研报。先用渗透率判定行业阶段:低空经济 2024 年才被写入政府工作报告,产业链处于 0 → 1 阶段,渗透率 < 5%。这是导入期。然后按导入期的研究重点切:① 触发 `business-model-feasibility`——卖什么?卖给谁?频次弹性怎样?eVTOL 是高频低单价还是低频高单价?② 触发 `market-sizing`——TAM/SAM/SOM 三口径测算,导入期不必精确,但要算清"假设爆发的上限"。③ 触发 `hypothesis-driven-research`——先列假设(政策驱动/技术突破/消费升级?),再做 MECE 验证。不要一上来就投。

### 示例 2:新商业模式早期怎么评估

**用户问题**

"有个 SaaS 创业项目找我投资,他们说 ARR 已经 1000 万了,值得投吗?"

**skill 如何判断**

- 触发 `business-model-feasibility`,两步法
- 第一步:销售可行性——时间对标(SaaS 通常 6-12 个月成单)、空间对标(海外/国内哪些类似产品验证过)、频次弹性(用户使用频率/月)
- 第二步:利润可行性——UE 模型(LTV/CAC、回收期)、终局视角(3-5 年后这个市场会怎样)

**最终回答示例**

> 不要只看 ARR 1000 万就拍脑袋。用两步法:① **销售可行性**——SaaS 标准成单周期 6-12 个月,他们用了多久?如果 < 3 个月就有 1000 万 ARR,要警惕是否靠降价/亏损换市场;反之,如果 18 个月还没到 1000 万,要警惕销售效率。空间对标看海外(美国 SaaS 普遍 ARR/客户 > $50k vs 国内 < ¥10 万),频次弹性看用户使用强度。② **利润可行性**——算 LTV/CAC,健康 SaaS LTV/CAC > 3,回收期 < 18 个月;同时看终局:3 年后如果市场只剩他们一家,LTV 能涨多少?如果只占 10% 份额,UE 模型还成立吗?再触发 `moat-analysis`——他们有什么护城河?是资源垄断(独家代理)、网络效应(用户越多越好),还是只有成本优势(短期内更便宜)?成本优势不是护城河。

### 示例 3:TAM/SAM/SOM 市场规模怎么估算

**用户问题**

"市场部让我写一个行业报告,让我估算'中国宠物食品'市场规模。我不知道从哪开始。"

**skill 如何判断**

- 触发 `market-sizing`,三口径 + 三方法
- 三口径:TAM(总市场)、SAM(可服务市场)、SOM(可获得市场)
- 三方法:需求法(自上而下)、供给法(自下而上)、供需匹配法(交叉验证)

**最终回答示例**

> 三口径分清才能避免"算出来 1000 亿但实际只能做 5 亿"的笑话。① **TAM**(中国宠物食品总市场)——需求法:宠物数量 × 单宠年均消费;或者供给法:全球宠物食品市场 × 中国占比(中国宠物渗透率只有美国的 1/3,所以 TAM 有上限)。② **SAM**(你能服务的市场)——如果做进口高端,只看一二线城市 + 高收入养宠人群;如果做国产中端,会大很多。③ **SOM**(你 3 年内能拿下的份额)——通常 TAM 的 1-5%,取决于竞品密度。三方法交叉验证:需求法给你天花板,供给法给你产能上限,供需匹配法检查假设是否站得住。最后用"拆未知量为已知量"原则:宠物数量从《中国宠物行业白皮书》查,单宠消费从艾瑞数据查,渗透率从京东宠物数据查——不要自己拍脑袋。

### 示例 4:怎么判断一家公司有没有真正的护城河

**用户问题**

"这家公司毛利率 60%,比同行高 20 个点,是真有护城河吗?"

**skill 如何判断**

- 触发 `moat-analysis`,护城河只有两种构造
- 资源垄断(牌照/原料/渠道独家)或网络效应(用户越多越好)
- 成本优势只是结果(规模/经验带来的),不是护城河本身
- 用客户决策/购买/使用三环节检查客户关系护城河

**最终回答示例**

> 高毛利不等于护城河。先分类:① **资源垄断**(牌照/原料/渠道独家)——比如某品牌有独家原料产地或政府牌照,别人进不来,这是真护城河。② **网络效应**(用户越多越好)——比如微信、滴滴、某些 SaaS 平台,用户越多体验越好,这是真护城河。③ **成本优势**——这只是规模/经验的结果,如果对手也能扩规模,你就会被追上(参考瑞幸 vs 星巴克)。具体到这家 60% 毛利率公司:如果是因为产品差异化(高端品牌定位),那要看客户决策链——是冲动消费还是理性比较?如果是冲动消费,品牌力就是护城河;如果是理性比较,客户会随时切换到更便宜的替代品。再看客户购买:是否锁定在某个渠道(独家入驻)?客户使用:是否有迁移成本(数据/习惯/工具链)?三环节都答不出,那 60% 毛利只是暂时的。

### 示例 5:周期性行业什么时候买

**用户问题**

"化工是典型的周期股,现在价格已经涨了 50%,该追吗?"

**skill 如何判断**

- 触发 `capacity-cycle-timing`,产能周期四阶段 + 顶底信号
- 顶信号:外来者大量扩产、龙头开始扩产、资本开支比 > 1.5、库存高企
- 底信号:龙头开始减产、外来者退出、资本开支比 < 1.5、价格跌破现金成本

**最终回答示例**

> 不要追涨。周期股的核心是"别人贪婪我恐惧"。四个阶段识别:① **繁荣期**(价格高、利润好、全行业扩产)→ 准备卖出 ② **衰退期**(价格跌、利润压缩)→ 等待 ③ **萧条期**(价格跌破现金成本、龙头减产、外来者退出)→ 准备买入 ④ **复苏期**(价格回升、库存重建)→ 买入并持有。顶信号:外来者大量扩产(他们都看到钱了,要小心),龙头扩产(他们也开始乐观了,常常是顶部),资本开支比(资本开支/折旧) > 1.5 = 行业在过度投资。底信号:龙头减产(他们最先感知到供过于求),资本开支比 < 1.5 = 行业在收缩。现在价格涨 50% + 看到扩产新闻 = 大概率是繁荣期末段,准备卖出而不是追入。再触发 `industry-valuation`——周期股用 EV/EBITDA + 净现金/总市值(破产风险) + ROE 历史分位,不要用 PE(利润顶部时 PE 反而最低,会误导)。

### 示例 6:不同生命周期行业估值用什么方法

**用户问题**

"消费医疗和医疗器械都是医疗行业,但 PE 差很多。哪个估值方法对?"

**skill 如何判断**

- 触发 `industry-valuation`,不同生命周期用不同估值锚
- 导入期:看管线/订单/PS(收入不确定时 PE 无意义)
- 成长期:看 PEG + 增速(用未来 3 年 CAGR 算 PEG)
- 成熟期:看 PE/DCF + ROE
- 衰退期:看 PB + 清算价值

**最终回答示例**

> 消费医疗(医美/口腔)已成熟,器械(手术机器人/创新耗材)在导入/成长期,不能用同一个估值锚。① **相对估值隔离噪音**——用"行业 PE ÷ 全 A PE"而不是绝对 PE,排除货币政策/利率的影响。② **生命周期估值切换**——导入期/成长期用 PS(收入还没起来),或 PEG(假设 25% 增速,给 PEG = 1 的估值);成熟期用 PE/DCF/ROE;衰退期用 PB。③ **赔率概率**——目标价 ÷ 当前价 = 赔率(向上空间),你判断概率正确性的把握 = 胜率;赔率 × 胜率才是预期回报。④ **交易拥挤度**——如果一个行业已经被机构重仓(持仓 > 历史 90 分位),即使便宜也不要碰;反过来,机构低配 + 基本面改善 = 最佳入场时机。⑤ **预期差**——市场对增速的预期 vs 你的判断,差距越大越好。消费医疗给 PE 25-30,器械给 PS 8-15 + 增速预期,本质是给"未来的现金流"定价。

### 示例 7:怎么从零开始研究一个行业

**用户问题**

"我想从零研究'人形机器人'行业,不知道从哪开始,怕遗漏关键信息。"

**skill 如何判断**

- 触发 `hypothesis-driven-research`,假设驱动的研究方法论
- 第一步:列假设(人形机器人的核心驱动力是什么?技术突破?成本下降?政策推动?)
- 第二步:MECE 拆解(每个假设拆成可验证的子假设)
- 第三步:逐个验证(数据/调研/专家访谈)

**最终回答示例**

> 不要漫无目的地找资料。先用假设驱动法:① **列主假设**——人形机器人的爆发需要"硬件成本 < ¥10 万 + AI 大模型能跑通 + 应用场景明确"三个条件。② **MECE 拆解**——硬件成本拆成"减速器/伺服电机/传感器/电池"四项;AI 大模型拆成"感知/决策/运动控制"三层;应用场景拆成"工业/家庭/医疗"三块。③ **逐个验证**——减速器看绿的谐波/双环传动的产品参数 + 价格;AI 看特斯拉 Optimus / Figure 02 / 优必选的视频 demo + 实际步态;应用场景先看特斯拉工厂内部部署数据(可信度高),其次看工厂客户的反馈。**注意来源纪律**——触发 `research-source-filtering`:专家访谈要避免"报喜不报忧",找真正用过的工程师而不是 PR;数据口径要统一(出货量 vs 装机量 vs 销售额);数据有立场时(分析师/公司)要交叉验证。最后用 `pyramid-insight-extraction` 从一堆研报里提炼核心观点,用 `scqr-storyline` 按受众调整输出顺序。

## 这些 skill 是怎么生成出来的

这套 skill 使用 **cangjie-skill** 的 RIA-TV++ 流水线生成,整个流程分六个阶段:

1. **整书理解(Adler 分析)**——用 Mortimer Adler 的分析阅读法,对全书做结构、解释、批判、应用四步拆解,产出 `BOOK_OVERVIEW.md`
2. **并行提取**——同时派 5 个专项提取器(框架、原则、案例、反例、术语),从原文中提取候选方法论单元
3. **三重验证筛选**——每个候选必须通过三项检验:书中至少有 2 处独立佐证(跨域)、能回答书中未明说的新问题(预测力)、不是常识(独特性)。通过率通常只有 25-50%
4. **RIA++ 构造**——将验证通过的内容按 R(原文引用)/ I(用自己的话重写)/ A1(书中案例)/ A2(未来触发场景)/ E(可执行步骤)/ B(边界与盲点)六个维度结构化
5. **Zettelkasten 链接**——找出 skill 之间的依赖、对比、组合关系,生成 `INDEX.md` 和引用图
6. **压力测试**——为每个 skill 设计包含诱饵题的测试用例,未通过的回炉重做

每个 `SKILL.md` 都是这个过程的真实产出。
