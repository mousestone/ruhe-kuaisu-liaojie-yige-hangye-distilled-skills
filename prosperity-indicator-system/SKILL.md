# 景气度指标体系构建

## R — 原文 (Reading)

> "我们要寻找的指标有两类--一类是前瞻性指标，另一类是高频同步指标……我们把这一篮子指标叫作'行业景气度指标体系'。"
>
> — 肖璟，《如何快速了解一个行业》第8章

## I — 方法论骨架 (Interpretation)

行业研究不是一次性工作——外部因素持续变化,需要用高频数据持续验证之前的中长期判断。这就是景气度指标体系。

**选指标的硬标准(两条)**:一、能反映行业基本面、帮助判断业绩;二、更新频次足够高(月/周/日)。理想情况还具备前瞻性。

**指标分两类**:前瞻性指标(感知趋势,提前于业绩变化)和高频同步指标(及时跟踪验证,与业绩同步)。

**两条构建路径**:
- 纵向——沿产业链找核心驱动环节,用它推断上下游(如房地产拉动上下游:新房销售→家电/建材/装修)。
- 横向——按行业类别找关键指标:上游看价格库存、中游看产销量、必选消费看通胀、可选消费看房地产、服务业看宏观、TMT 看产业周期。

**两条纪律**:
- 理解指标背后的逻辑,不能刻舟求剑——指标之间"打架"时要分析原因(可能是政策扰动/经销商行为,而非需求变化),这是主观投资相比量化投资的优势。
- 用一篮子指标交叉验证(如白酒用批价+库存+打款+开瓶率),不要被单一指标的短期波动牵着走。

## A1 — 书中的应用 (Past Application)

### 案例 1:新能源车景气度——销量+量价二维跟踪
- **问题**: 如何持续跟踪新能源车行业景气、验证增长判断?
- **方法论的使用**: "量"维度——中汽协/乘联分会月度销量、动力电池装车量、充电桩保有量;"价"维度——上游锂/钴化合物价格、中游四大电池材料价格、动力电池价格。2021 年销量持续超预期带动锂电板块普涨。
- **结论**: 用高频"量+价"指标验证中长期判断。
- **结果**: 2021 年销量从预期 200 万辆到实际 331 万辆,超预期带动板块行情;2023 年碳酸锂从 60 万跌破 10 万元/吨。

### 案例 2:白酒批价——单一核心指标的威力
- **问题**: 白酒行业如果只能选一个景气度指标,选什么?
- **方法论的使用**: 选批价(散瓶飞天茅台批发价):数据可得性强(公众号可查)、及时反映供需并直接影响业绩(顺价销售决定出厂价上限)、是品牌力最直接体现。
- **结论**: 茅台股价与批价相关系数 0.95(五粮液 0.81)。
- **结果**: 2020 年初批价跌破 2000 元股价跌超 10%,批价破 3000 元股价接近翻倍。

### 案例 3:茅台拆箱令——理解指标背后逻辑
- **问题**: 批价几天内大幅波动,是需求变了吗?
- **方法论的使用**: 分析背后逻辑——茅台为遏制囤积实施拆箱令,导致"箱茅"供应减少、"散茅"增加,引起批价波动;取消时反向波动。
- **结论**: 短期批价波动未必反映需求变化,可能是公司政策或经销商行为所致。
- **结果**: 证明必须理解指标背后的逻辑,不能把单日波动当景气信号。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想长期跟踪某行业,需要建立一套"该看什么数据"的监测体系时。
2. 判断"XX 行业最近景气吗"、验证之前的中长期判断时。
3. 想知道产业链哪个环节是"核心驱动"、该盯哪个数据时。
4. 看到两个指标打架(价涨但量跌),想搞清楚真实景气时。

### 语言信号 (用户的话里出现这些就应激活)

- "该跟踪什么指标来判断 XX 行业?" / "最近 XX 行业景气吗?"
- "前瞻指标 / 高频指标 / 月度数据" / "批价 / 库存 / 开工率 / 销量"
- "帮我建个指标看板" / "验证一下我之前对 XX 的判断"
- "which indicators track this industry?" / "leading indicators" / "is the industry doing well"

### 与相邻 skill 的区分

- 与 `industry-lifecycle-staging` 的区别: 生命周期是几十年的长期阶段,景气度是阶段内的短期高频验证——本 skill 是"持续跟踪"工具,生命周期是"一次性判定"框架。
- 与 `capacity-cycle-timing` 的区别: 产能周期是中期供需结构(季度/年级),景气度是高频验证(月/周/日)——产能周期信号(库存/资本开支)是景气度指标的重要来源,但时间尺度不同。
- 与 `hypothesis-driven-research` 的区别: 景气度体系是"已建立判断后的持续验证",假设驱动是"研究开始时如何高效找答案"——前者是被跟踪的指标库,后者是研究方法。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确定行业核心驱动,选纵向或横向路径**
   - 纵向: 画出产业链,找最核心的驱动环节(需求源头或瓶颈环节),沿它推断上下游。
   - 横向: 按行业类别(上游/中游/必选/可选/服务/TMT)套用关键指标模板。
   - 判停条件: 若对行业毫无了解,先快速用 `hypothesis-driven-research` 或资料建立基本面认知,再选指标。
   - 完成标准: 明确"采用哪条路径 + 选定的核心环节/类别"。

2. **筛选指标,配齐"前瞻+高频同步"两类**
   - 对每个候选指标过两条件:能反映基本面?更新频次够高(月/周/日)?
   - 确保一篮子中至少有一个前瞻指标(感知趋势)和一个高频同步指标(验证业绩)。
   - 对每个指标写下其背后的供需逻辑(它为什么反映景气)——这是刻舟求剑的解药。
   - 完成标准: 指标清单(每项:名称/频次/类型/背后逻辑)。

3. **持续跟踪 + 交叉验证 + 解释打架**
   - 定期更新指标,标注变化方向与幅度。
   - 多指标交叉验证,不一致时分析原因(政策/经销商/季节性/情绪 vs 真实需求变化)。
   - 用景气结论校验之前的中长期判断,必要时迭代。
   - 完成标准: 输出"当前景气判断(好/平/差) + 关键指标走势 + 指标打架的解释 + 对原有判断的修正"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 一次性研究(只需要现在的一个判断)时——景气度是持续跟踪工具,一次研究用假设驱动即可。
- 分析单家公司经营数据时——本 skill 是行业层面。

### 作者在书中警告的失败模式

- **指标刻舟求剑**(ce23 / c52):白酒批价短期波动就改变判断——茅台拆箱令等政策/经销商行为会造成噪声,需理解逻辑+一篮子交叉验证。
- **单一指标一波动就改观点**:把高频噪声当趋势(与 ce23 同源)。
- **时间差陷阱**(ce19):微信群/大V 的"消息"是第 N 手且混假消息,不是景气度数据——景气度要基于可验证的高频数据,不是小道消息。

### 作者的盲点 / 时代局限

- **偏投资专用**(ce48):景气度指标体系服务于二级市场验证业绩,对求职/创业等场景价值有限。
- **数据时效**(ce50):书中具体行业指标(白酒批价等)和数值是案例,构建新行业体系需自行更新。

### 容易混淆的邻近方法论

- 与"宏观景气"(PMI 等)混淆:作者强调行业级、高频、可验证的指标,不是宏观景气指数。
- 与"产能周期"混淆:景气度是高频短期,产能周期是中期结构——产能周期信号可纳入景气度篮子,但不要混为一谈。
