# 资讯源与研报处理

## R — 原文 (Reading)

> "我们千万不要盲目相信单一资讯源。当需要获取重要数据时，我们应该从不同的数据源获取数据并进行交叉验证。"
>
> — 肖璟，《如何快速了解一个行业》第12章 第1节

## I — 方法论骨架 (Interpretation)

研究的输入质量决定输出质量。面对任何资讯源,默认"它可能不可信",用以下检查链把关:

**数据源的两条检查**:先搞清数据如何定义和收集(口径),再搞清数据提供方的立场(有没有造假动机)。官方机构可能出于政绩虚报,调研机构可能用甲方数据"加工"成行业报告,金融数据库也可能有录入错误与口径变更——都要交叉验证。

**券商研报的筛选四思路**:看热度(热门≠高质量)、看团队(奖项+公募分仓收入+路演勤奋度)、看推荐(是否有专门路演/合集收录)、看内容(假设合理/论据扎实/观点明确/可证伪/论证环环相扣)。**最关键的信号:研报报喜不报忧,刻意回避某方面往往暗示该方面有问题**——只讲市场空间不讲竞争格局,可能因为竞争格局很糟糕。

**专家访谈的纪律**:先通过公开渠道掌握基本知识再约专家(专家不是科普工具,其价值在非公开信息);判断专家的认知边界(很多专家有"偶像包袱",会把问题引向自己熟悉的领域);结论不能无条件接受,须追问事实依据与逻辑——**事实和逻辑远比结论更重要**。

**心态**:投研本身要做大量假设,追求"模糊的正确"而非"精准的错误"——不同口径数据交叉验证后取区间即可。

## A1 — 书中的应用 (Past Application)

### 案例 1:调研机构数据造假——作者亲历
- **问题**: 作者代表企业方沟通全行业用户画像报告,想知道数据源。
- **方法论的使用**: 对方回答"把你们公司的用户画像数据给我们,合理加工即可"——一个企业的数据无法代表行业(该企业商业模式有护城河、用户画像特殊)。
- **结论**: 非官方调研机构可能"无中生有"造假,需查立场、交叉验证。
- **结果**: 作者拒绝合作,因数据来源不可靠。

### 案例 2:白酒批价作为景气指标——先验证再使用
- **问题**: 白酒行业该信哪个高频数据?
- **方法论的使用**: 批价三大优势:数据可得性强(公众号可查)、及时反映供需并直接影响业绩、是品牌力最直接体现;茅台股价与批价相关系数 0.95。
- **结论**: 挑指标要看"可得性+逻辑性+代表性"。
- **结果**: 批价从 2000 元跌破到 3000 元突破,与股价高度同步。

### 案例 3:专家预测失准——新能源车专家曾悲观
- **问题**: 2015 年前后请教新能源领域资深专家,对方非常悲观。
- **方法论的使用**: 专家身处行业内部、看到大量微观问题(浮躁/违规),但难判断这些局部问题是否是快速发展的必要代价——"盲人摸象、只见树木不见森林"。
- **结论**: 专家擅长提供事实与细节,对宏观趋势预测能力有限;要用数据判断趋势。
- **结果**: 新能源车成为制造业"明星",证明不能全信专家情绪。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿到一份研报/报告/数据,想判断可不可信、该不该采信时。
2. 一个关键数据几个来源说法不一,想交叉验证时。
3. 要访谈专家/大V,想知道怎么问、怎么评估其回答时。
4. 研究遇到数据,想确认口径与立场、避免被造假数据带偏时。

### 语言信号 (用户的话里出现这些就应激活)

- "这份研报可信吗?" / "哪个数据源靠谱?" / "数据怎么验证?"
- "这个专家说的能信吗?" / "要不要听这个观点?"
- "口径 / 立场 / 交叉验证 / 数据造假"
- "is this report reliable?" / "verify this data" / "credible source" / "should I trust this expert"

### 与相邻 skill 的区分

- 与 `hypothesis-driven-research` 的区别: 假设驱动是"怎么研究的方法",本 skill 是"研究时怎么选源/验源"——前者是流程,后者是流程中的质量关卡。
- 与 `pyramid-insight-extraction` 的区别: 来源筛选是输入端把关,金字塔是处理端提炼——先保证输入可信,再谈提炼质量。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **评估来源性质与立场**
   - 判断来源类型(官方/调研机构/券商/数据库/专家/媒体),明确其利益与立场(政绩动机/冠名费/维护关系/流量)。
   - 对数据:搞清定义口径与收集方式;对观点:找出其事实与逻辑支撑。
   - 判停条件: 若来源明显有造假动机(如数据源语焉不详、无收集方式说明),直接降级或弃用,标注原因。
   - 完成标准: 来源清单(每个:类型/立场/口径/可信度初判)。

2. **交叉验证 + 识别"回避信号"**
   - 重要数据从 ≥2 个独立来源获取并比对,差异大时回溯原始信源。
   - 读研报/报告时找"刻意回避项"——只讲好处不讲某方面,那个方面可能有问题。
   - 完成标准: 每个关键数字的交叉验证结果 + 报告的回避项清单。

3. **访谈专家(如需要):先补基础,再追问事实,最后独立判断**
   - 访谈前先掌握基本知识(专家价值在非公开信息,不在科普)。
   - 评估专家认知边界(履历+擅长领域),追问"依据是什么"而非只听结论。
   - 对专家结论保持"事实和逻辑远比结论更重要"的独立判断。
   - 完成标准: 输出"可信度结论 + 关键事实 + 存疑点 + 建议采信的部分"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 分析行业本身(那调用其他 skill)——本 skill 只负责"输入质量",不替代分析。
- 简单查一个事实(直接查权威源即可,不必启动完整过滤流程)。

### 作者在书中警告的失败模式

- **官方机构造假**(ce27):地方政绩动机虚报,需与社会融资规模等难造假的指标交叉验证。
- **调研机构造假**(ce26/c60):无中生有或用甲方数据加工成"行业报告"。
- **数据库错误与口径变更**(ce34):彭博等数据库有录入错误、社会融资规模口径被央行调整数次——查原始信源。
- **研报报喜不报忧**(ce28):分析师为维护关系回避负面,不提什么比提什么更值得注意。
- **专家认知边界不清/偶像包袱**(ce25)、**专家预测失准**(ce24)、**新财富评选论资排辈**(ce42)、**买方机构套现陷阱**(ce43)。

### 作者的盲点 / 时代局限

- **A 股/中文资讯生态**(ce49):书中信源(百荣酒价、进门财经、新财富等)是中国语境,海外研究需替换为对应信源。
- **数据时效**(ce50):具体榜单与工具迭代快。

### 容易混淆的邻近方法论

- 与"文献综述"混淆:综述是"收集覆盖",本 skill 是"逐个验真"——两者要结合。
- 与"媒体素养/辟谣"混淆:本书聚焦研究信源(研报/数据库/专家),比泛媒体辟谣更结构化。
